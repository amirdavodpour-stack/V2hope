# HOPE V2 — Premium Max Design System Contract

## Intent
V2 is experience-led and uses V1/V19 as a frozen foundation. The design system is a product contract, not a visual theme.

## Required layers
1. **Tokens** — spacing, radii, breakpoints, surfaces, typography, motion, touch targets and UI layers.
2. **Primitives** — page frame, panel, hero, section header, tag, search and metrics.
3. **State** — default, hover, pressed, focused, disabled, loading, error and success where interactive.
4. **Responsive** — compact, medium, expanded and wide layouts; no horizontal overflow at compact widths.
5. **Accessibility** — semantic labels for meaningful composite surfaces, 48dp minimum interactive targets, reduced-motion support, RTL-safe layout.
6. **Consistency** — flagship screens consume shared primitives instead of inventing one-off tokens.

## Premium quality bar
Premium Max means visual hierarchy, information density, interaction clarity, motion restraint, accessibility and responsive behavior are all deliberate. Gradients, shadows and animation alone never qualify.

## V2 gate
A new flagship screen is not considered V2-complete until it uses shared tokens/primitives, covers interaction states, works at compact and expanded widths, passes accessibility review, and has a regression test.
